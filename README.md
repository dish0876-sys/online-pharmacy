# 💊 Онлайн-Аптека (Backend)

Серверное приложение для онлайн-аптеки, разработанное на **Java 17** и **Spring Boot**.
Проект решает задачу поиска, заказа и доставки лекарственных средств с соблюдением правил продажи рецептурных препаратов.

## 🚀 Реализованный функционал

*   **Аутентификация и безопасность:** Регистрация, вход по сессиям (JSESSIONID), роли (Клиент, Фармацевт, Администратор).
*   **Каталог товаров:** Просмотр товаров, поиск, фильтрация по рецептурности.
*   **Корзина и Заказы:** Добавление в корзину с проверкой остатков на складе. Оформление заказа, отмена с возвратом остатков.
*   **Рецепты:** Загрузка файлов рецептов клиентами. Проверка (одобрение/отклонение) фармацевтом.
*   **Валидация:** Запрет оформления заказа на рецептурные препараты без одобренного рецепта.
*   **Панель фармацевта:** Управление статусами заказов (сборка, отправка).
*   **Панель администратора:** CRUD товаров (с мягким удалением), управление остатками, отчеты по продажам и топ-товарам.
*   **Обработка ошибок:** Глобальный обработчик исключений (возвращает понятные JSON-ответы вместо 500 ошибок).

## 🛠 Технологии

*   Java 17
*   Spring Boot 3 (Web, Data JPA, Security)
*   Hibernate
*   H2 Database (в памяти)
*   Lombok
*   Maven

## ⚙️ Как запустить проект локально

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/dish0876-sys/online-pharmacy.git
    cd online-pharmacy
    ```

2.  **Запуск:**
    В корне проекта выполните:
    ```bash
    # Для Windows
    mvnw.cmd spring-boot:run
    
    # Для Linux/Mac
    ./mvnw spring-boot:run
    ```
    Или просто запустите класс `OnlinePharmacyApplication` в вашей IDE (IntelliJ IDEA).

3.  **База данных:**
    Приложение использует встроенную H2 Database (in-memory). Данные сбрасываются при каждом перезапуске.
    Доступ к веб-интерфейсу БД: `http://localhost:8080/h2-console`
    *   JDBC URL: `jdbc:h2:mem:pharmacydb`
    *   User Name: `sa`
    *   Password: (оставить пустым)

4.  **Файлы:**
    Загруженные рецепты сохраняются в папку `uploads/prescriptions/` в корне проекта.
